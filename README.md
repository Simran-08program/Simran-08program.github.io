# Simran Ghosh — Dark Modern Portfolio

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Add your real profile photo
Replace `profile-placeholder.svg` with your photo named `profile.jpg`, then update the image line in `index.html` to:
`<img id="profilePhoto" src="profile.jpg" alt="Simran Ghosh" />`

The + button lets you preview a photo in your current browser session. For a permanent published photo, use the replacement steps above.

## Publish free with GitHub Pages
1. Sign in to GitHub as `Simran-08program`.
2. Create a new **public** repository named `Simran-08program.github.io`.
3. Upload all files from this folder to the repository root (not the ZIP itself).
4. Open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/root`.
5. Save and wait for GitHub Pages to publish.
6. Your site address should be `https://simran-08program.github.io/`.

## Before publishing
- Add your real profile photo.
- Add your LinkedIn URL if you want it displayed.
- Add repository links and screenshots for projects you are ready to show.
- Confirm project descriptions and experience dates are accurate.
